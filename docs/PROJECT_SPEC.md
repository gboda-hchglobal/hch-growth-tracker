HCH Growth Tracker

Purpose:
Allow parents of children with hypochondroplasia
to record growth data and visualise it against
digitised HCH growth charts.

Platforms:
- Android
- iOS
- Web

Authentication:
- Google Login
- Email/Password

Features:

Child Profiles

Measurements:
- Height
- Weight
- Arm Span
- Sitting Height
- Head Circumference

Growth Charts:
- Interactive
- Zoom
- Historical plotting

Reports:
- PDF Export

Database:
Firebase Firestore
